# Voice Guide — Draft Post

Style constraints for the `draft_text` field generated by Draft Post
(`src/agent/draft_post.py`) — the one piece of AI-generated text in this
project that gets published to a real X account as-is, with no human
rewrite step in between. These are about tone and grounding, not mechanics
like the character limit, which stays defined in code alongside the schema.

- Write in a natural, human voice.
- No hashtag spam.
- No generic hype filler.
- No fabricated numbers or facts — everything stated must already be
  present in the provided theme summary, rationale, or example posts.
- State the trend plainly, as a person who follows this topic closely would.
